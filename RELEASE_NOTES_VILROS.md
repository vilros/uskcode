# Vilros Menu Boards 1.0.0

Guided-install distribution of Michael Ogrinz's MIT-licensed Max's Menu 1.0.0-rc3.

- One Raspberry Pi serves up to ten screen addresses on a local network.
- Phone/laptop editing, prices, availability, themes, daily schedules, staff accounts and backups.
- Fresh-install helper installs prerequisites and enables automatic Pi startup.
- Complete restaurant guide and printable staff checklist.
- Bundled local assets/fonts, original license and source attribution.
- Reproducible installation ZIP with SHA256SUMS; runtime credentials/data excluded.

Read README.md and docs/RESTAURANT_GUIDE.md before installation. Player kiosk behavior and Pi/TV hardware must pass the guide's acceptance checklist. This distribution contains an upstream release candidate and is marked as a prerelease accordingly.
